## Purpose

A scored, honest check of whether Hello Gorgeous can produce **signed, current documentation** if IDFPR, a pharmacy partner, a malpractice carrier, or a plaintiff’s attorney asks. Work it with the office manager and Ryan. Check **Yes / No / Not sure** for every item. Count **Yes only**. Every No or Not sure is a gap.

This is the Hello Gorgeous version of a 35-point practice audit. It maps to **this binder**, live intake/consent systems, and Illinois rules — not a generic national kit.

---

## How to use

1. Sit down with the person who can actually find the file (not “I think we have that”).
2. **Yes** only if the document exists, is dated, and is signed when a signature is required. A draft in the repo that Ryan has not signed is **No**.
3. Tally Yes answers (max 35). Use the score bands and the 30-day sprint at the end.
4. File the completed, signed audit in this binder. Do not backdate.

## What an inspector typically asks for first

Produce these without a scavenger hunt:

1. Current licenses (physician, APRN, RNs) and the **signed** collaboration / medical director agreement  
2. Signed SOPs for services you actually sell (injectables, laser, **GLP-1**)  
3. Service-specific consents (sample + a real chart)  
4. Emergency protocols + the physical kit  
5. Staff competency / training files  
6. A handful of complete charts (intake, consent, note, product/lot if injectable)  
7. If the visit is complaint-driven: that patient’s entire file, unaltered  

IDFPR and similar surveys compare **what is written** to **what staff do**. A protocol nobody follows is its own finding.

## Gaps this practice should not paper over

These are the failure modes that show up in board matters. Score them inside the 35 items above; this list is the priority order if time is short.

1. **Unsigned protocols** — drafts in Git are not a medical record.  
2. **Staff working outside documented scope** — MA/aesthetician vs RN vs APRN vs what the agreement allows.  
3. **Emergency kit and drills that do not match the paper.**  
4. **Generic consent** covering GLP-1 or laser.  
5. **Expired or aesthetics-only collaboration language** covering an RX weight-loss line.  
6. **Photos or PHI in personal texts / social without HIPAA authorization.**  
7. **Marketing that names brand pens when patients receive compounded vials**, or “FDA-approved” on compounded GLP-1.
