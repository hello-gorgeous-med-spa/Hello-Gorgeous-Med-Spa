# Clinical cheat sheet standard (Hello Gorgeous)

**Reference example:** `public/staff/protocols/cheat-sheets/duocratus-laser-ipl-marissa-cheat-sheet.pdf`  
**HTML source:** `docs/manuals/marissa-duocratus-cheat-sheet.html`

## How Dani wants these made

1. **One printable page** (letter) — black stamp borders + HG pink accents (`#E6007E` / `#FF2D8E`).
2. **Operator-facing** — SAFE start vs AGGRESSIVE columns, not marketing fluff.
3. **Device + modality named** in the title (e.g. Zemits DuoCratus).
4. **Golden rules + hard stops** called out (test spot, MD escalate).
5. **Pre / after care** for the client conversation.
6. **Sources footer** (manuals / HG protocols).
7. **Ship to:** Desktop PDF for handoff + `public/staff/protocols/cheat-sheets/` + register in `lib/clinical-cheat-sheets.ts`.
8. Build HTML first → Chrome headless print-to-PDF.

When asked for a new cheat sheet, copy this layout before inventing a new format.
