## 3) Consult Desk & Proposals — sales flow

**This is the path for weight loss, injectables, Morpheus8, packages, etc.**

### Pipeline (memorize this)
**Consult → Proposal → Send → Book in Square → Care guides**

### A) Start a consult
**URL:** [/admin/proposals/consults/new](https://www.hellogorgeousmedspa.com/admin/proposals/consults/new)

1. Choose the vertical (e.g. weight loss / injectables / Morpheus8)
2. Enter client name, contact, notes
3. Tap **Enter consult room**
4. Screen + educate in the room (follow the prompts)

**Queue of open consults:** [/admin/proposals/consults](https://www.hellogorgeousmedspa.com/admin/proposals/consults) → **Open room**

### B) Build a proposal
**URL:** [/admin/proposals/new](https://www.hellogorgeousmedspa.com/admin/proposals/new)

1. Client + contact details
2. Pick package / services
3. Use **Auto-generate options** when available
4. Tune Essential / Recommended / VIP
5. **Save**

**All proposals:** [/admin/proposals](https://www.hellogorgeousmedspa.com/admin/proposals)  
Use **Preview**, **Edit**, or **Chart** as needed.

### C) Send the plan to the client
Open the proposal → **Preview**, then:
- **Copy public link**
- **Email** / **SMS**
- **PDF**
- Square payment / financing links when applicable
- **Send care guides** when treatment is booked

### D) Book the visit (staff side)
Open **Book in Square** (seller calendar):  
[Square Appointments calendar](https://app.squareup.com/dashboard/appointments/calendar)

Book **for** the client. Do **not** send them only to the public book page unless they prefer self-booking.

### What we expect from consults
- Every serious inquiry gets a **consult room** or a **proposal** — not just a sticky note
- Plans are **sent** the same day when possible
- Visits are **on Square** so the whole team sees the schedule
- If a client is unsure, log the note in the consult/proposal and tell Danielle — open communication beats guessing

## 4) Consents — get forms signed before treatment

### Front-desk reality (use this most days)

**From Hub / today’s Square appointments**
1. Find the client on today’s Square list
2. Tap **Start consents**
3. That creates/links the Hello Gorgeous visit + consent pack
4. Open or copy the **iPad kiosk link**
5. Hand the iPad to the client (or text the link when appropriate)

**On the iPad**
- Go to [/kiosk](https://www.hellogorgeousmedspa.com/kiosk) **or** open the short link you generated
- Client enters phone → check-in → **Sign consent forms**
- Kiosk signing sessions last the visit (hours, not minutes). If you still see expired, start the visit again from `/kiosk`.

**If forms are still outstanding**
- On the appointment: **Resend SMS**, **Sign on iPad**, or **Get kiosk consent link**
- Client self check-in: [/checkin](https://www.hellogorgeousmedspa.com/checkin)

### Admin consents library (templates)
**URL:** [/admin/consents](https://www.hellogorgeousmedspa.com/admin/consents)  
This manages templates and signed totals. Day-to-day signing starts from **Hub / appointment / kiosk**, not by editing templates.

### What we expect for consents
- No treatment without needed forms signed (or Danielle/Ryan override)
- Check Command Center consent tracker at open and before each arrival
- If a packet fails or a link expires — regenerate and tell the team; don’t leave the client stuck in the lobby

We’re building a calmer, clearer Hello Gorgeous. That only works if we talk.

- **Ask early** if you don’t know which tool to use  
- **Say something** if a client is upset, forms are broken, or Square doesn’t match the desk  
- **Write it down** in Command Center tasks / consult notes — not only in a group chat that disappears  
- **No silent struggle** — text Danielle the same day
