Treatment Proposals — How to Use

Build → share → collect deposit · Vitamins B4G2 · Exosome healing add-on · Square “Proposal” pay type

Use Admin → Proposals to build a consult plan, send a live link, take a Square deposit or pay-in-full, and send care guides. Clients can also start at /build-your-proposal — you polish and close.

Building the plan

  1. Tap a quick-add package if it fits (fixed package price).
  2. Add services: weight-loss dropdown, peptides grid, injectables (unit presets for toxin), InMode, skin, laser.
  3. Add Vitamin injections while treating — 1 / 2 / 3-month B4G2 plans and/or à la carte shots.
  4. Toggle AnteAGE Exosomes — Advanced Healing Add-on ($250) for procedure days.
  5. Click Auto-generate options, then adjust % off, $ off, or custom totals.
  6. Save.

Auto-generate often suggests exosomes + a vitamin plan on Recommended/VIP when Morpheus8, microneedling, Solaria, Quantum RF, or packages are selected. Remove anything you don’t want.

Do / don’t

Do

  • Get phone + email before send
  • Confirm which plan you’re charging
  • Offer Cherry on larger totals
  • Stack vitamins + exosomes on series
  • Edit & re-send if the consult changes

Don’t

  • Promise outcomes or guarantees
  • Invent prices — use catalog plans
  • Create duplicate Square links blindly
  • Skip care guides on lasers / M8 / needling

Quick alternate — RX Invoices

Need only a payment link (deposit / balance / custom) without a full 3-option proposal? Open /admin/rx-invoices → track Proposals → send. Still labeled Proposal in Square.
