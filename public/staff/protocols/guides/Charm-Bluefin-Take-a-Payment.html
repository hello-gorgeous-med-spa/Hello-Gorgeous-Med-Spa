How to take a payment (Bluefin / Charm)

You are not looking for a Square terminal. Med-spa services stay Square. RE GEN / Charm patient charges go through Bluefin inside Charm.

If Bluefin says “no charge” / grand total won’t calculate: Charm thinks the invoice is $0. Fix the invoice first. Bluefin cannot invent a dollar amount.
  1. Billing → Invoices → + Invoice → pick the patient. Leave Encounter blank if this is just a product/visit charge.
  2. If an Insurance / Payer is selected, clear it. You are cash/self-pay. Insurance makes Patient Responsibility $0 until a claim posts — Bluefin then has nothing to charge.
  3. In Procedures (or Products), search a code/name. On that row, click the Charge box and type the dollars (example 299.00). Tab out. Quantity at least 1.
  4. Watch the bottom: Total / Balance Due must show $299, not $0. If Charge stays blank, Charm never sums it.
  5. Payment details: check Pay Invoice in full so Payment Amount fills with that total.
  6. Then check Use Payment Gateway → Key-In or reader → Approve (not Save as Draft — gateway invoices cannot stay draft).
Still $0? Settings → Billing → Fee Schedules — your codes are priced at $0. Type the Charge on the invoice anyway; that overrides.

A. Patient in the chair — fastest (use this)

  1. Charm: accounts.charmtracker.com/signin
  2. Open the patient (search their name).
  3. On their Dashboard, find Billing → click Add Payment.
  4. Type the dollar amount.
  5. Payment method = Card.
  6. Check Use Payment Gateway. (If you don’t see that box, skip to “Stuck” below.)
  7. Beneficiary = your Bluefin account (Hello Gorgeous / RE GEN).
  8. Input type:
    • Key-In — type the card (phone / no reader).
    • EMV Chip Reader — pick the device, hit Add, then tap/insert on the reader.
    • Swipe — cursor in Card Information, swipe, then Add.
  9. Click Add. Wait for the receipt. That is the payment.

B. They’re not here — send a pay link (easiest for telehealth)

  1. Charm → Billing → Invoices (or make a + Invoice first if nothing is owed).
  2. Open the unpaid invoice → Send Invoice (or ⋯ → Send Invoice).
  3. Check Send Payment Link (email and/or SMS).
  4. Pick the Bluefin beneficiary. Send.
  5. They pay from the text/email or from their Charm patient portal Pay button.

C. One-click from an existing invoice

  1. Billing → Invoices → ⋯ on the unpaid row → Add Payment.
  2. Same as A: Card + Use Payment Gateway + Add.

Or Billing → Receipts → + Payment → pick patient → same checkboxes.

D. Backup only — PayConex (not the chart)

Use this if Charm is down and you still need to run a card. Then you must still record it in Charm as a payment so the balance isn’t wrong.

  1. Go to secure.payconex.net
  2. Virtual Terminal / Sale → amount → card → process.
  3. Go back to Charm and Add Payment as a recorded payment (do not check Use Payment Gateway a second time or you will double-charge).
One-time setup so the checkbox appears every time:
Charm → Settings → Billing → Bluefin → Default Settings
Turn on: auto-select Use Payment Gateway · default Input Type (Key-In until a reader is mapped) · optional store card on file.
Beneficiary lives under Settings → Billing → Bluefin → + Bluefin Beneficiary (PayConex account # + API key — already done if you saw Bluefin live).
Do not: charge Square for an RX/Charm visit · charge PayConex AND Charm gateway for the same card · overwrite Charm’s Bluefin postback URL · type a card into our website (that is not this processor yet).

Charm’s own page: Bluefin Patient Payment Gateway (video at the top).

Stuck: no “Use Payment Gateway” box = Bluefin beneficiary not mapped to this facility, or your user isn’t a biller. Call Charm support or Bluefin service@bluefin.com — don’t guess a second MID.
